# 🛒 E-Commerce Conversion Funnel Analysis

## 📌 Project Overview

This project analyzes the e-commerce customer journey using **Power BI** to identify conversion patterns, customer drop-offs, and revenue performance across different business dimensions.

The project was completed as part of my **Data Analysis Internship at SYNTECXHUB**.

---

## 🎯 Objective

The objective is to understand how customers move through the purchase funnel:

**Browse → Add to Cart → Checkout → Purchase**

and identify opportunities to improve conversion and reduce customer drop-offs.

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Analysis
- Data Visualization
- Business Intelligence
- Funnel Analysis

---

## 📊 Key KPIs

- Total Browses
- Total Add-to-Cart Sessions
- Total Checkouts
- Total Purchases
- Overall Conversion Rate

### Key Result

**Overall Conversion Rate: 10.8%**

---

## 🔍 Analysis Performed

### 1. Conversion Funnel
Analyzed customer movement through:

Browse → Add to Cart → Checkout → Purchase

### 2. Drop-off Analysis
Identified customer losses between each funnel stage.

### 3. Device Analysis
Compared conversion performance across different devices.

### 4. Marketing Channel Analysis
Compared conversion rates across acquisition channels.

### 5. Product Category Analysis
Analyzed revenue contribution by product category.

### 6. Regional Analysis
Compared revenue performance across regions.

---

## 💡 Business Value

The analysis helps businesses:

- Identify major customer drop-off points
- Improve conversion rates
- Optimize marketing channels
- Understand device-level customer behavior
- Identify high-performing product categories
- Compare regional revenue performance
